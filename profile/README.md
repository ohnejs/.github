# ohne

A zero-dependency TypeScript framework for the web. "ohne" is German for "without".

You get a database, an HTTP API, auth, uploads, internationalization and a dashboard.
There is no build step: Node 26 runs your `.ts` files directly, and `ohnejs` is your only dependency.

```sh
npm create ohne my-app
```

**[Documentation](https://ohne.dev/docs)** · [Website](https://ohne.dev) · [Framework](https://github.com/ohnejs/ohnejs)

## Packages

- [`cms`](https://github.com/ohnejs/cms) - pages, routes, SEO and a live preview editor
- [`client`](https://github.com/ohnejs/client) - reads CMS pages and wires the live preview, for any frontend
- [`next`](https://github.com/ohnejs/next) · [`nuxt`](https://github.com/ohnejs/nuxt) - render CMS pages in Next.js or Nuxt
- [`pg`](https://github.com/ohnejs/pg) - Postgres for the database
- [`s3`](https://github.com/ohnejs/s3) - S3 storage for uploads
- [`images`](https://github.com/ohnejs/images) - the reference image service

## Start from

- [`next-starter`](https://github.com/ohnejs/next-starter) · [`nuxt-starter`](https://github.com/ohnejs/nuxt-starter) - a website with pages, blocks and live preview
- [`todo`](https://github.com/ohnejs/todo) - lists and tasks with accounts and an AI assistant
- [`rayleigh-next`](https://github.com/ohnejs/rayleigh-next) · [`rayleigh-nuxt`](https://github.com/ohnejs/rayleigh-nuxt) - a portfolio with gallery, blog and contact form
